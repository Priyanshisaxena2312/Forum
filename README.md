# FormHub 💬

FormHub is an interactive discussion platform where users can share thoughts, express opinions, participate in debates, and explore different perspectives with AI-powered conversation insights.

## Features

- **Discussion Hub:** Create, share, and explore community discussions.
- **Perspective Debates:** Express opinions and engage in meaningful debates.
- **AI Conversation Insights:** Generate AI-powered insights from discussions.
- **Ideas to Action:** Transform discussions into meaningful ideas and actions.

## Tech Stack

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Installation

1. Clone this repository.
2. Move the project folder into XAMPP's `htdocs` directory.
3. Start Apache and MySQL.
4. Import the project database using phpMyAdmin.
5. Configure database credentials in the project.
6. Open `http://localhost/FormHub` in your browser.
